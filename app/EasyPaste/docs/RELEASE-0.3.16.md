# EasyPaste 0.3.16

- **Extraction en texte brut.** « Extraire le texte d’une zone » copie uniquement du texte, sans HTML ni tableau enrichi.
- **Ordre visuel conservé.** Les lignes sont lues de haut en bas et leur contenu de gauche à droite. L’ID reste sous le nom ; les petits libellés voisins restent sur la même ligne. Les blocs sont séparés par une ligne vide.
- **Colonnes lisibles.** Les fragments nettement espacés sur une même ligne sont séparés par ` | ` dans le texte extrait.

Ce changement concerne les nouvelles extractions. Les anciennes entrées de l’historique conservent leur contenu ; utiliser « Copier en texte brut » pour les recopier sans mise en forme. La qualité de reconnaissance dépend de la lisibilité de l’image ; les tableaux complexes peuvent nécessiter une vérification.

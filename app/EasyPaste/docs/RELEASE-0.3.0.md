EasyPaste peut désormais se mettre à jour directement depuis son menu et ses réglages.

- Rechercher, télécharger et installer une nouvelle version sans remplacer l’app à la main.
- Vérifications automatiques facultatives, une fois par jour.
- Installation protégée pendant les captures, les annotations et les partages.
- Historique, collections et réglages conservés.
- Applications signées et notarisées par Apple ; téléchargements et informations de mise à jour signés avec Sparkle.

Cette première version doit être installée une fois avec le DMG. Les suivantes pourront être installées depuis EasyPaste.

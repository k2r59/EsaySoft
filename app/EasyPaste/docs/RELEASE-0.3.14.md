# EasyPaste 0.3.14

- **Historique : retrouvez votre emplacement après un collage.** La recherche, la sélection et le défilement sont conservés pour retrouver facilement les éléments voisins. L’élément collé remonte dans l’ordre chronologique de la bibliothèque. Une nouvelle copie externe, y compris depuis un iPhone, remet la barre sur le contenu le plus récent et efface les anciens filtres.
- **Nouvelle capture défilante.** Dans le menu Capture, choisissez « Capture défilante… », sélectionnez une zone puis faites défiler doucement vers le bas. Vérifiez l’image longue dans l’aperçu avant de l’enregistrer, de la copier ou de l’annoter. La capture porte sur une zone d’une fenêtre et d’un écran ; évitez les en-têtes fixes et conservez du contenu commun entre deux passages.
- **Capture texte mieux structurée.** Les fragments situés sur la même ligne sont réunis, les blocs séparés et les retraits conservés. Les colonnes espacées restent sur leur ligne.
- **HTML et texte copiés ensemble par défaut.** La capture texte fournit une version HTML reconstruite pour les applications compatibles, ainsi qu’une version texte. « Copier en texte brut » et « Coller sans mise en forme » restent disponibles. Le HTML est reconstruit à partir du texte reconnu ; il ne provient pas du code original de la page.
- **EasyPaste Web 0.3.0.** Interface de l’extension revue, copie de page avec mise en forme, récupération des sous-titres YouTube avec choix de langue, aperçu modifiable et horodatages facultatifs. Parcours d’installation et de connexion proposé dans EasyPaste pour Chrome et les navigateurs Chromium compatibles, dont Arc.
- **Téléchargements web depuis l’extension.** Choix vidéo MP4 ou audio MP3, qualité vidéo et suivi pendant et après le téléchargement. Fonctionne avec les sites et médias compatibles avec le moteur disponible. Nécessite EasyMusic ou yt-dlp et FFmpeg installés sur le Mac ; Node est recommandé pour YouTube. Les moteurs ne sont pas installés automatiquement. Les sources nécessitant des cookies, les DRM et les directs en cours ne sont pas pris en charge.
- Correction du menu de capture pour les outils d’accessibilité, et exclusion des commandes EasyPaste de la capture défilante.

L’extension reste une installation locale guidée ; cette mise à jour n’est pas une publication sur le Chrome Web Store.

Validation : 404 tests Mac en mode Release sans échec (2 tests réseau optionnels ignorés) et 81 tests de l’extension réussis, reconnaissance OCR réelle et import HTML macOS. Capture défilante vérifiée dans Arc sur 7 passages, avec aperçu, enregistrement et copie PNG. Les téléchargements MP4/MP3 et sous-titres ont également fait l’objet d’essais réels pendant la préparation. Aucun test ne garantit la reconnaissance de tous les caractères d’une image peu lisible ni la compatibilité de tous les sites.

EasyPaste s’ouvre désormais en mode clair.

- Trois apparences dans Réglages → Général : Clair, Sombre et Automatique.
- Automatique suit le réglage de macOS ; le changement s’applique sans relancer l’app.
- Le choix est conservé sur ce Mac.
- Couleurs adaptées dans l’historique, la barre rapide, les réglages et les éditeurs.
- Contrastes renforcés pour les textes, la recherche, les boutons et les messages d’erreur.

Le contenu de l’historique et les couleurs des captures restent inchangés.

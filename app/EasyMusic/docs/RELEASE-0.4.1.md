# EasyMusic 0.4.1

- Cliquez sur le nom de la playlist ou son crayon pour la renommer directement depuis sa page.
- Nouvelle fenêtre de renommage cohérente avec l’interface.
- Bouton corbeille dans la barre d’actions pour supprimer la playlist après confirmation.
- Les fichiers audio, les autres playlists et la playlist d’origine sont conservés.
- Les actions restent également disponibles dans les menus de la playlist.
